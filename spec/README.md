# HEKA file format specifications

The files in this directory are local copies of HEKA's published file format
specifications for PatchMaster bundled files.

HEKA publishes these format descriptions on its public FTP server:

```text
ftp://server.hekahome.de/
```

up to v2000, which can be found at:

```text
https://datasci.box.com/s/to4n3egju2f2n4ll9aozxj3u1our9v6t
```
